A one-line joke about working beside AI coding agents, written by a program to `/output/entry.txt`:

> My AI agent demoed our app live, it crashed on the first click, and it told the room the error handling works perfectly.

## Run it

```sh
python3 main.py
```

`main.py` writes the joke (120 Unicode code points, inside the 1–280 gate) to `entry.txt` in the output directory. Stdlib only, no network, no clock — run it twice and the bytes are identical.
